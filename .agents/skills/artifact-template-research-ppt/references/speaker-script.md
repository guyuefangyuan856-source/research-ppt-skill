# 逐页讲稿与时间

讲稿是能够口头讲出的说明，不能只复制幻灯片的短句，也不应堆入超过指定时间的大段文字。

每页以 `## 第01页 标题` 这样的二级标题开始，顺序和标题与逐页清单一致。包括建议时长、指图提示、口语正文和原文来源。正文中的最后一句可承担过渡作用；不要在每页重复机械的过渡句。

首页介绍题目、汇报人和核心问题。结束页收束结论并邀请讨论。正文按听众理解顺序解释专业名词，尤其是不同绩效指标、变量与单位，避免先给结论再补必要条件。

从逐页清单统一生成 PPT 备注与 Markdown：二者均包含原样的 `title`、`seconds`、`cue`、`speech`、`source`。Markdown 开头写明汇报人和最终 PPTX 的文件名，并给出逐页时间总览。

默认计划 1170 秒，上限 1200 秒，时间包括翻页、停顿和指图，不包括额外讨论。参数覆盖后重新分配时长。公式、核心机制和主结果通常需要更多时间，封面与结束页较短，不平均分配每页时间。

核查每页文字量与预计语速，必要时实际排练。秒数求和仅证明计划未超时，不能声称已经完成真人口头计时。需要很长解释时精简主讲，详细说明作为标明“不计入主讲”的讨论提示保存。
