# 模板与视觉验收

使用前读取模板或用户指定模板，查看全部参考页，再选用与内容匹配的结构。保留的默认参考是已清理的 19 页占位模板，不要求最终页数也是 19。

默认视觉系统：16:9，原始尺寸 12192000 × 6858000 EMU（1280 × 720 CSS 像素），微软雅黑，深蓝主色 `#024282`，青色强调 `#12859A`，白色与浅蓝正文区。封面使用校园背景和校徽，正文保留左上蓝色标记、页眉分隔线、右上校徽与页码。校徽与背景不属于 MIT 授权。

沿用标题、解释、表格和左右图文的层级。参考模板的正文区大致为 x=55–1225、y=150–630，结论和来源位于页脚。坐标仅适用于默认模板；用户替换模板时重新检查尺寸和几何结构。

## 制作约束

- 使用 Presentations 支持的导入/复制流程和 `@oai/artifact-tool`，不以整页截图代替可编辑幻灯片。
- 默认公式使用原文截图；正文和符号解释保持可编辑。来源字号可以小于正文，但在演示尺寸仍需可读。
- 先精简冗余文字、调整分区和留白，再考虑缩小字号。避免内容压到校徽、页码、来源或结论上。
- 清理参考页的旧文字、图像、备注、隐藏页及无用媒体关系。检测 `［`、`[Paper title`、`请替换` 等占位符；真实同形字符需要人工判断。

## 验收顺序

1. 复核论文事实、符号和图表条件，核对讲稿与 PPT 同页。
2. 使用 Presentations 的最终化工具检查包完整性、字体、尺寸、可编辑表格及几何布局。
3. 渲染最新最终文件。逐页查看完整尺寸，同时用缩略图检查整体节奏，与参考比对配色和重复元素。
4. 检查题目、汇报人、日期、页码、开场、结束页、公式边界、图例、行距、溢出与重叠。对改动页重新渲染。
5. 对最终 PPTX 运行本技能的交付核查，并在交付前执行报告新鲜度验证。

自动检查只能证明其列出的结构和一致性。只有实际检查过，才可声称视觉审核通过；未在 PowerPoint 打开时，不能声称已在 PowerPoint 验证。
